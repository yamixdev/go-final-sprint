# Планировщик задач

Веб-приложение для хранения задач с датой, заголовком, комментарием и правилами повторения. Фронтенд находится в `web`, сервер и API написаны на Go, данные хранятся в SQLite.

## Возможности

- добавление, просмотр, изменение и удаление задач;
- отметка задачи выполненной;
- повторяющиеся задачи: по дням, годам, дням недели и дням месяца;
- настройка порта через `TODO_PORT`;
- настройка пути к базе через `TODO_DBFILE`.

Не выполнены необязательные задания: поиск задач, JWT-аутентификация и Docker.

## Запуск

Нужен Go 1.27.0.

```powershell
go run .
```

Откройте в браузере `http://localhost:7540`.

При необходимости можно указать порт и путь к базе:

```powershell
$env:TODO_PORT = "7541"
$env:TODO_DBFILE = "C:\\path\\to\\scheduler.db"
go run .
```

## Тесты

Сначала запустите сервер в отдельном терминале. Затем из корня проекта выполните:

```powershell
go test ./tests
```

Настройки находятся в `tests/settings.go`:

- `Port = 7540`;
- `DBFile = "../scheduler.db"`;
- `FullNextDate = true` для полной проверки правил повторения;
- `Search = false` и `Token = ""`, потому что эти дополнительные задания не реализованы.
